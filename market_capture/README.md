# Ianto 市场调研

所有日常运行代码均在此目录内。详情单品、搜索页整理和多平台搜索共用原 Ianto，不需要 Node 服务、篡改猴或 Windows 自启动任务，不调用 AI。

## 首次启用

1. 在 Chrome 扩展管理页重新加载原 Ianto，然后刷新已打开的商品页。
2. 打开 Ianto 的“采集设置 / 待同步记录”。已配置的浏览器可直接使用；首次使用时填写 App ID、App Secret 和飞书数据表链接，点击“保存并检查连接”。
3. 连接检查通过后，详情页点“收录”，搜索页点“整理”。以后只需正常使用浏览器。

应用配置仅存在当前浏览器的扩展存储中，不写入商品网页，也不包含在采集 CSV 中。

## 调研分析

从 Ianto 批量搜索下方的“调研分析”或采集设置页进入完整面板。图表、筛选和商品明细在同一处展示，直接读取已配置的飞书表，不需要额外服务，也不调用 AI。打开时先显示上次快照再读取当前飞书；读取失败明确保留上次快照的时间，点击“刷新飞书数据”可重新读取。飞书删改在下次成功刷新后体现，不从采集历史恢复已删除的商品。

- “新建一批调研”设置名称、开始和结束日期（北京时间，包含两端），还可限定具体采集批次。日期与采集批次是数据边界；产品、关键词、国家、平台是独立分析条件。同一维度内多选为“或”，不同维度之间为“且”。
- 产品按已有主题初步归组，可在“整理产品分组”手动把多个关键词放到同一产品下；关键词仍独立可选。大小写、Unicode 等价字符和多余空格统一匹配；重音差异、翻译词与近义词不自动合并。各批调研可维护自己的产品归组，归组只改变面板，不修改飞书。
- 平台、关键词、国家对比及合并观察共用同一套条件；自由组合可叠加维度。可保存包含日期、采集批次、条件、对比维度与统计口径的视角。产品分组、批定义和视角保存于当前浏览器的 Ianto 中。
- 默认在每组内按国家、平台、商品 ID（缺失时用链接）和规格去重，取最新观测；也可保留每次采集。同一商品属于多个关键词时可出现在多个组中，分组之和可能大于全局去重商品数。
- 展示样本数量、按币种划分的价格分布和中位数、价格与评价积累、销量对比、字段可用情况、组合明细及对应商品。多币种不混算，缺失不当作零；无法识别的销量不计入销量指标，不把评价数量当销量。销量按来源、周期、下限口径分开，显示各组商品的中位数，不相加为平台总销量。采集样本不代表平台全部市场，也不代表市场份额。
- 图形可联动筛选，商品可查看原文和采集来源。分析页导出的是当前筛选的分析商品或组合对比表；采集设置中的“导出这次 CSV”仍保持单次原始快照及飞书统一表头口径。
- 飞书只读分析接口分页读取完整表，校验分页与返回数量后才替换快照，空白行不参与分析。读取最多十万条，超过时明确停止。分析不会创建字段、修改视图或写入商品记录。

面板提供18项可选分析组件（16种图表、2种清单），可按“常用总览、价格与竞争、关键词与配置、商品筛选、持续跟踪”切换，或自行勾选并随视角保存。未选择的图表不计算、不渲染；这些分析均由浏览器中的规则和数值计算完成，不调用AI。

- 商品列表支持单件或批量整理：直接归入产品、标记本批相关性、商品类型、自定义配置标签、人工同款组、候选状态和分析备注。单链接没有搜索词时也能归组，不会把所有缺失搜索词的商品混到每个产品下。未标记商品默认仍参与分析。
- 类型、配置、同款组、候选和分析备注按国家、平台、商品与规格身份在多次观测间复用；相关性属于当前这批调研，新批可继承再调整。整理仅保存在当前浏览器的Ianto中；原始飞书资料保持原样。
- 新增评分和评价数量分布、搜索广告构成、店铺/品牌构成、类型/配置矩阵、关键词商品重合、价格与销量、评分与评价积累、人工同款比价、单商品跟踪、重复采集变化及候选清单。缺数据时说明缺什么，不补造数值或市场判断。
- 搜索广告构成只统计搜索页观测，广告标记未知单列。关键词重合只比较同国家、平台、来源下的实际搜索词。每页前20/50个位置的分析选项仅限制搜索页，不删减原始全页采集，也不排除单链接单品。
- 数值条件可筛价格、评分和评价数量；价格范围必须指定一种币种。同款组需人工确认，按国家和币种拆开比较。趋势按来源、币种或搜索条件拆线，搜索排序未知时只画点；单次采集不制造趋势，评价增量不当销量。
- 当前分析商品CSV包含整理标记，采集设置的“导出这次CSV”继续跟随飞书统一表头。分析清单不会自动给出“值得做”或利润结论。

## 开发意见

搜索页整理或详情页收录成功保存到Ianto后，自动弹出可选的“开发意见”输入框。可以留空、粘贴多行文字或以后使用自己的模板；整段文字保存在一个文本单元格内，保留空行与换行，不拆字段。搜索页意见应用于本次采集的每条商品，单品意见仅应用于本次这一条。

输入即保存到Ianto，停止输入后后台同步飞书；点框外或按Esc收起，悬浮钮旁“意见”可再次打开，刷新同一标签页后也可恢复最近一次采集的入口。新采集会打开新的空白意见。意见不阻塞商品资料和图片任务；失败或断网时保留待同步状态，可通过“补传未完成内容”重试。最长20000字，后续编辑或清空会更新对应的意见单元格。

飞书“开发意见”为文本字段，各视图当前均在最后一列；字段ID用于后续改名的对应。仅在填写意见且该字段缺失时补建该文本字段，不创建其他字段，不新增或补回商品记录。开发意见只更新已确认的本批商品回执，全文回读核对后才标为成功。本地仅保存一份批次意见，避免搜索页采集量大时重复占用本地存储。

## 运行口径

- 商品资料先入表，首图在后台上传并回读确认；首图失败保留状态，自动重试最多三次，也可点击“补传未完成内容”继续处理。
- 队列按批次持久保存。关闭浏览器时暂停，下次启动浏览器后继续处理。请求结果不明时先按采集编号核对，避免重复入表。
- 搜索词来自页面已采用的结果词或搜索 URL，保留大小写、重音。Ianto 原始输入词另存。直接打开详情页时，未知的搜索词与位置留空。
- 调研主题不用预先设置：独立搜索按当前实际搜索词自动填写，可靠来源详情沿用该来源主题；直接打开且无来源的详情可留空。Ianto 发起的一次多平台搜索共用本次主题，留空则用本次输入词，下一次搜索不会带入上次主题。
- 如需给不同搜索词自定义同一主题，采集前点悬浮钮旁的「⋯」，在当前商品/搜索页填写并保存。本页主题只用于之后的采集，搜索页更换 URL 后不套用，已保存记录不受影响。设置和同步记录也从此菜单进入；采集本身不会打开设置页。
- 搜索页点击“整理”后自动滚动本页，边加载边记录主结果商品；到底且商品和页面高度稳定 2.5 秒后结束，随后回到原位置。Temu 已登录时继续点击当前结果的“See more / 加载更多”，不点击翻页、购买或推荐词。未登录时保留已识别结果并提示登录后重新整理，避免被平台转到登录页后丢失本次结果。不自动翻页或请求商品详情。保留重复曝光和广告位置；虚拟列表按平台序号或滚动窗口的重叠顺序定位，推定位置会写明依据，未知页码留空。
- 滚动时显示已识别数量；点击“停止”保存已识别内容，按 Esc 取消且不保存。页面持续加载超时、加载更多无进展、仍有商品卡未识别或达到每次 10000 个商品的容量时，会明确标注“未确认全部”，并在该批次备注中保存原因；不会将部分采集显示为完整结果。登录和平台验证页面会说明当前限制。
- 评分、评价数量和销量分别读取；分期、旧价及付款提示不作为销量。页面只有星级图形时注明图示含义，不编造精确评分。页面未展示的销量或评价数量保持为空。
- 页面展示的配送国家优先于 Ianto 目标国家；币种按实际价格符号识别，支持 AUD。速卖通可从结果路径恢复搜索词，并核对搜索框；商品链接中明确的配送国家可作为页面依据，不把界面语言当成国家。
- Ianto 更新后会检查已打开的支持站点并补上采集圆钮；页面重绘移除圆钮时自动恢复。已经有效的圆钮不会重复注入。
- 飞书保存累计结果。每次点击“整理”或“收录”各算一次采集，在设置页对应批次旁点击“导出这次 CSV”，只导出那一次的商品快照。搜索页一次整理 48 个商品就导出该次的 48 个，详情页一次收录 1 个就导出该次的 1 个。文件名含采集时间和批次短号。
- 同一数据表的各表格视图共用列名、列顺序和显隐；在任一视图调整后，Ianto 自动同步到其他视图，各视图的筛选、分组和记录排序保留。浏览飞书时在操作后自动检查，页面可见期间每15秒核对；浏览器后台每分钟核对。关闭浏览器时暂停，下次启动继续处理。
- 单次 CSV 导出前读取并核对统一表头，空列保留。无法读取最新配置或表头尚未同步完成时停止导出并提示原因。字段改名后仍按字段 ID 对应商品信息。商品内容保留采集时的信息，CSV 首图列为图片链接；后续人工新增的列在快照中没有值时留空。
- 每个平台的页面规则需要随实际页面结构维护。
- 设置页的“补传未完成内容”会继续上传未入表的商品资料、待上传和上传失败的首图；跳过重试等待时间，失败首图开始新一轮尝试，正在上传和已成功的内容保留。只使用已采集的数据，不重新采集网页；没有未完成任务时明确提示。
- 设置页的“飞书现有商品”直接读取飞书，统计平台商品ID、商品标题、商品链接至少有一项不为空的行；空白行另行提示。刷新失败会显示错误，不用历史采集数量替代当前数量。“刷新状态”会立即重新读取飞书数量和连接情况，以及待同步任务、采集历史，不启动补传；页面打开期间每30秒自动核对一次飞书，历史批次和任务进度每5秒刷新。
- 连接区默认显示两行：飞书当前商品数与更新时间，以及采集记录中首图已上传、待上传、失败的张数。刷新结果合并在第一行，不另占一行。有失败时直接点击该行的“失败 Z 张”展开或收起原因，失败为 0 时只显示数字；按钮解释悬停可见。
- “商品资料待入表（个）”统计尚未确认写入飞书的商品数量；下方首图的“待上传”按图片张数统计，两个数字分别表示资料入表与首图上传进度。
- 采集历史与飞书当前数据用途不同：历史用于导出单次采集快照，飞书删改不会改动已保存的快照。历史首图数表示当时的上传结果。刷新只读取数据，不会把已删除的飞书商品重新上传。
- 采集历史按“时间 · 国家 · 平台 · 采集方式 · 商品数量 · 本次主题”显示，不展示某一个商品的标题；商品标题仍保存在该次快照、CSV 和飞书记录中。无法从采集记录确定国家或平台时显示未知。
- “清空全部历史”会一起清除采集索引和完整商品快照，包括未显示在最近列表中的历史缓存；飞书配置、飞书表内商品及尚未同步的任务单独保留。删除单条也会同时清除对应索引和快照。

`features/multisearch_platforms.js` 维护批量搜索国家、平台和链接；`data.js` 负责字段和校验；`table.js` 保存当前表的字段 ID 绑定；`headers.js` 负责统一表头；`feishu_page.js` 触发表头核对；`feishu.js` 负责认证、写表及附件；`direct.js` 负责持久任务队列；`background.js` 负责与 Ianto 接入；`search.js` 负责搜索页滚动加载和商品快照；`content.js` 负责圆钮和页面采集。

开发检查：安装根目录 `package.json` 声明的开发依赖后运行 `npm run test:market`。测试包括脱敏后的实际商品卡片结构及滚动、续传、表头、历史、CSV 场景；这些开发工具不参与扩展日常运行。
